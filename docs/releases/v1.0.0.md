# Release v1.0.0 — 2026-11-10

- 導覽選單縮小主項、次項按鈕與留白，保留垂直捲動、關閉按鈕與鍵盤焦點處理。

既有旅程、到訪、拼圖、照片與訂單資料不需重設；本版未更動登入、付款或獎勵規則。兩個作品為獨立頁面，不與主程式共享旅程進度，也不代表館方官方服務。

## 驗證與限制

- 本機只確認選單、園區模擬逛展與小小辦公室可開啟，並看到兩個作品的 3D 場景；未另外執行完整測試或驗證所有作品操作。
- GitHub Pages 沿用既有 lint、單元測試與 build 發布流程；執行結果以本次工作流程紀錄為準，不沿用前版驗收數字。
- 未進行真機、現地 QR、真實登入或付款驗證。獨立園區頁含約 20 MB 內嵌資產，首次載入時間受裝置與網路影響。
