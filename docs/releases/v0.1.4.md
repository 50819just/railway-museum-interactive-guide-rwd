# v0.1.4｜探索模式、附近提醒與商品詳情

2026-11-06

- 新增 Google／LINE 模擬登入；單人、親子與探索方式可一起設定，出發前再確認。開始收集拼圖後鎖定玩法，需要更換時可從旅程設定重新開始。
- 提供「推薦路線」與「自在漫遊」，自由選站時依當下站點出題，不再混入前站題目或連錯狀態。
- 調整額外任務：第 3、6 次到訪固定提供，第 8 次有 50% 加碼機會；離館補助共用名額，全程最多新增 3 次，舊版已發機會保留。
- 在第 2、4 站加入「附近探索」，可預覽附近站點故事；有可用任務時顯示本站問答入口。預覽不計入到訪，也不消耗拼圖。
- 商品新增詳情視窗，未集滿拼圖也能查看圖片、材質、長寬高與外框體積；查看不會建立訂單或預留商品。
- 操作補充改用空心問號查看，旅程設定集中到頁底單一文字入口；保留重設前確認與照片紀錄。

既有旅程、拼圖、照片與預訂紀錄不需重設。登入仍是同裝置模擬流程，不提供真實第三方登入或跨裝置同步。商品尺寸為本專案訂定的設計規格，非供應商實物量測。

本版一併納入既有綠界 STAGE 測試入口：不會真實扣款、不送印、不提供正式商品領取資格。請勿輸入真實信用卡或個人資料。
