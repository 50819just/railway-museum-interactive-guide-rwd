# v0.1.0 — 探索與答題體驗更新

版本日期：2026-11-02。比較基準：上次已上版的 `1e8cb3a96a1e1992bb01b3b1287e22378d6e1578`（2026-10-31）。這是本專案首次建立語意化版本號，先前package為0.0.0，沒有既有Release tag。

## 新增

- 10個站點、每站3題，共30題展區知識題庫，附一般版、簡單版、答案解釋與官方來源。
- 新挑戰優先選已到訪站點，三題題號建立後固定保存；答對可查看官方原文。
- 兌換區兩張禮物Banner每5秒自動輪播，圖片與文案一起淡入淡出；新增暫停／播放，保留手動圓點。
- 「旅程服務」頁底顯示版本與日期，方便回報問題。

## 調整

- 探索主畫面只保留Top nav拼圖進度，移除重複的到訪統計與最後確認摘要；各站到訪狀態仍在探索旅程內。
- 額外挑戰改用金黃色、寶箱圖示與輕微呼吸邊框，加入右上紅點；移除沒有額外內容的收合箭頭，直接開始／繼續答題。
- 地圖未讀紅點移到按鈕右上角，箭頭改為垂直置中的SVG。
- 三題進度用橫線串接圓點：已完成到目前為金色，未到的節點與連線為淺灰。
- 一般答題說明收進預設關閉的「答題規則」；即時錯題提示與儲存失敗警告仍直接顯示。
- 輪播在閱讀互動、頁面隱藏、離開可視區或兌換視窗開啟時停止計時；系統減少動態設定停用自動播放。

## 資料與相容性

不需要重設收藏。既有已開始的挑戰沿用原題，保留題次與錯題紀錄；下一次新挑戰才使用展區知識題。拼圖收藏與實際到訪仍分開記錄。

本版未更動抽取機率、每次獎勵片數、兌換門檻、補差額、官方庫存或付款規則。新題庫依官方公開史料改寫，並非館方核定題庫；未納入另一聊天仍待審核的候選題目優化。

## 已知限制

- 仍是互動原型；兌換與差額為本機示範，不會付款、預留商品或核發館方正式領獎資格。
- 進度目前保存在同一裝置與瀏覽器；清除網站資料、換裝置可能無法接續。
- 官方活動商品、成本配額、正式服務時間／地點、資格有效期與後端核銷仍待確認。
- 尚未完成iPhone／Safari真機相機、下載及真雙機驗收；JS主包仍有超500kB警告。
