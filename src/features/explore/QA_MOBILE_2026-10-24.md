# 探索手機 UX 修正與 QA（2026-10-24）

## 範圍與判斷

使用者在園區移動時，需要先知道「下一站、已收集多少、到站如何領片」，再決定查看地圖或站點介紹。這是依程式與畫面作出的 UX 判斷，並非使用者訪談或可用性研究結果。

| 原有痛點 | 本次修正 |
| --- | --- |
| 手機先看完整地圖，任務與主動作位於下方 | 手機與 DOM 改為任務先行；桌面以 grid areas 維持左地圖／右任務 |
| 首屏缺少進度脈絡 | 簡短進度條、首輪依序集片、最後確認站；明確不是即時定位 |
| 開始探索會展開長圖文，且還需再按一次才能掃碼 | 「到站掃碼」直接開到站確認；「查看前往路線」獨立；介紹維持收合 |
| 預覽其他站之後不容易回到當前旅程 | 顯示預覽／已完成狀態及限制；一鍵回到下一站，不改進度 |
| 往下滑後找不到掃碼入口 | 原主動作滑出頂端才顯示快捷列，位於底部導覽上方；對話框開啟時隱藏 |
| 地圖被任務長卡推太遠 | 移除目前站重複的返回地圖按鈕，圖文收合；首屏已有查看路線與十站清單 |

未改站序、領片條件、資料模型、第二輪規則或正式核銷。相機權限並未因 UX 按鈕而自動開啟；到站確認仍由使用者另按「開啟相機掃碼」。

## Mobbin 參考（僅借鑑資訊層級，未複製品牌、圖像或版型）

實際檢視了工具回傳預覽，以下是畫面觀察及本專案推論，兩者分開：

- [Grab 路線預覽](https://mobbin.com/screens/d3e54b54-989f-41bb-8497-accc33bf451e)：畫面同時可見出發／目的地、路線與操作。推論：本專案應分開「知道去哪裡」與「抵達後領片」，不要求先展開站點介紹。
- [My BMW 目的地摘要](https://mobbin.com/screens/88e9bb25-5d99-4cfe-ac27-4b3cf1097a74)：地圖下有目的地與狀態摘要。推論：地圖需要文字任務脈絡，但本專案沒有 GPS，因此只顯示最後確認站而非即時位置。
- [Duolingo 下一步](https://mobbin.com/screens/345a05d1-9d96-4467-9746-8e87b752f691)：明確 UP NEXT 區塊與 CONTINUE 按鈕。推論：預覽站點不能把下一個可完成任務藏起來。
- [Liven 順序旅程](https://mobbin.com/screens/c9d2fcaf-4346-4ec2-86d7-7ea56f9bd04f)：已完成、目前節點與未解鎖節點以狀態區隔。推論：本專案保留已完成／下一站／待解鎖，不把預覽誤當成可跳站領片。

浮動列／焦點檢查亦參照 [W3C Focus Not Obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)。本次只驗證具體操作與量測，未宣稱整站符合 WCAG。

## 實際 QA

工具：CUA IAB DOM Tab，`browser.tabs.new()`，本機 Vite `http://127.0.0.1:5173/`。測試的是桌面瀏覽器手機尺寸，不是 iPhone 實機，也沒有聲稱已完成鏡頭實拍掃碼。到站回歸使用頁面內示範碼。

- 390 × 844：`innerWidth=390`、`innerHeight=844`、`scrollWidth=390`。最終初始頁掃碼 CTA y=407.906–459.906，地圖頂部 y=648.5，底部導覽 y=770–844；主動作在首屏，地圖可一鍵前往。
- 320 × 667：`innerWidth=320`、`scrollWidth=320`。1/10 接續頁 CTA y=429.304–481.304，導覽頂部 y=593；無水平溢出。320 地圖上快捷列文字可換行、不遮擋底導覽。
- 390 地圖快捷列：dock y=706–770，底部導覽 y=770–844，無重疊；點快捷列能打開目前站到站確認。
- 1280 × 900：`innerWidth=1280`、`scrollWidth=1280`。地圖 x=278–845.718、任務 x=873.718–1239.992，仍為左右雙欄。
- 未解鎖第 05 站預覽 → 回到下一站 01；進度仍 0/10，圖文不會被強制展開。
- 已完成第 01 站預覽（1/10）→ 顯示不重複發片 → 回到下一站 02；進度維持 1/10。
- 十站清單開啟／關閉：焦點恢復至原「十站清單」按鈕（`.task-route-button`），選站後焦點到站點卡。
- 01–10 依序到站 → 領片 → 略過合照 → 下一站，完整走過兩次；10/10 顯示完成紀錄、兌換預覽與紀念照入口。
- 10/10 完成後查看地圖：390 × 844 實測 dock y=706–770，底部導覽 y=770–844；顯示「首輪已完成・10 / 10 片」與「查看兌換預覽」。實際點擊後 URL 為 `http://127.0.0.1:5173/#train`。
- 本機 console warn/error：0。
- `npm run lint`、`npm run build`、`node --test tests/*.test.mjs`：通過（9 項既有相機測試；不冒充新增 UX 單元測試）。
