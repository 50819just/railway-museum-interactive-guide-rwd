# VibeCode AI 協作指引

本文件是規格區的協作補充，不另建一套與根目錄衝突的永久限制。

## 開發入口與現況

- 先讀根目錄 [AGENTS.md](../AGENTS.md)、[README.md](../README.md) 與本次涉及的程式。
- [EXTENDING.md](../docs/EXTENDING.md) 提供內容、頁面與規則變更範例。
- VibeCode/ 內部分文件仍是初期範本或歷史紀錄。「待填」「未授權」「起始頁」只代表其記錄時點，不能據此禁止目前已授權的功能開發。
- 最新需求定義要達到的目標，現有程式提供目前行為證據；遇到差異依 AGENTS.md 第 0 節判斷，不把 bug 當需求。

## 執行節奏

1. 檢查既有變更，確認任務範圍與相關文件；不是每次都要讀完整規格庫。
2. 文案、樣式、bug 與已授權功能可直接做必要的小改並驗證，不要求每個檔案再確認一次。
3. 目前的十站、四語、目錄、兩段導讀與樣式是可演進慣例，不是凍結要求。
4. 破壞資料、重大架構、額外服務費用、正式金流與發布操作，先確認當次授權和影響；已授權事項不重複請示。
5. 程式、測試與有效文件同步更新。不把文件中描述的未來流程當作已實作功能。
6. 回報已完成、測試、警告及未驗證項，不把本機檢查當成正式部署或真實服務驗收。

## 穩定底線

保護使用者資料、秘密、原始素材及未提交工作；不捏造場館資訊、合作授權、研究結果或測試證據。一般技術慣例可依新需求調整，安全與誠實底線不能只為方便而省略。
